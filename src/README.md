# Código del producto

El agente de frontend incorpora aquí módulos genéricos en `card/`, `editor/`, `panels/` y `state/`. El agente de integración incorpora `ha/` y participa en `state/` mediante PR coordinado.

La fundación no implementa tarjeta, editor, plano ni integraciones. No importar inventarios, planos reales, etiquetas personales, códigos RF ni adaptadores Browser Mod. Los esquemas son la autoridad del contrato; no mantener otra copia divergente dentro de cada módulo.
