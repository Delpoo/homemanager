# Lote 4: alternativas, Ahora y navegación

34 capturas exclusivamente ficticias: 1440x900 y 390x844, claro y oscuro; navegación adicional a 1920x1080. Fuente reproducible scripts/capture-redesign-lote4.mjs; huellas exactas en docs/public-assets.json.

## Comparación con las maquetas

- E11 usa la estructura de Alternativas del dibujo 6 de maqueta-modulos: lista, miniaturas, imagen por modo, fondo y vista previa. Mantiene el original geométrico y una acción explícita para alinear; los bytes se guardan aparte en HA.
- E12 conserva componentes del kit de vision-mockup sección 6. Se distinguen lista, editor y preview; los bloques se eligen por fuente sin ligar la vista a una categoría. Las capturas now-list y now-editor muestran ambas posiciones del área desplazable.
- E13 compara con sección 13. Capturas before-room usan el módulo de navegación/estilos del commit a88c8aa, no una simulación del defecto; el script comprueba que el clic anterior no navega. Las room actuales permiten clic/teclado y mantienen flechas dentro del viewport. El nombre inicial del espacio se retira: no es una etiqueta persistente.
- Modo pared fuerza sólo su paleta y su imagen oscura, muestra el panel wall y ofrece salida por icono en cabecera, sin añadir una fila al plano.
- Revisadas al cierre las vistas móviles de alternativas y editor Ahora, PC 1920 y pared. Se corrigieron ancho de editor y ubicación de salida; no se atribuye prueba con tablet física.
