# CP4 · Capturas comparadas

48 PNG originales: ocho vistas y cuatro referencias, en escritorio (1440×900) y móvil (390×844), claro y oscuro. Todos proceden de la casa inventada de las pruebas. Los archivos conservan el tamaño completo; las miniaturas sólo facilitan la comparación.

El contenedor flotante de edición es el de main: el inspector acoplado corresponde a CP3b. Las secciones nuevas usan los componentes de §6/§12. Las referencias oscuras aplican la clase `dark` ya definida en la maqueta, sin alterar su contenido.
