# Capturas actuales de E02

Capturadas el 31 de octubre de 2026 con sesiones y datos ficticios, desde `tests/card/task-screens.browser.spec.mjs`. Son pantallas del producto implementado. Se revisaron hojas de contacto y algunas imágenes a tamaño completo; esto no certifica todos los recorridos.

Se generaron 72 imágenes: 18 estados × escritorio/teléfono × claro/oscuro. **Este PR contiene 60**. La conexión con el equipo local se perdió al transferirlas; las otras 12 no están publicadas y no se sustituyeron con imágenes recreadas. Almacenamiento y editor/revisión de zonas tampoco tienen capturas en este conjunto.

Cada archivo admitido tiene origen, revisión y SHA-256 en `docs/public-assets.json`; la lista cerrada de nombres está en `scripts/public-assets.mjs`.
