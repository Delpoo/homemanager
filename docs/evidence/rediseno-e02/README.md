# Capturas E02 — lote 0

88 capturas ficticias: las 72 originales de E02 (incluidas las 12 cuya transferencia quedó interrumpida) y 16 del cierre: primer espacio, lienzo de zonas, revisión de movimientos y Almacenamiento, en escritorio/teléfono y claro/oscuro. No se sustituyeron capturas originales con imágenes recreadas.

Las nuevas usan 1440 × 900 y 390 × 844 píxeles, escala 1. Las originales móviles usan ese mismo viewport CSS con la densidad de Pixel 7 (1024 × 2216 píxeles en el PNG). Sólo se volvieron a capturar las dos vistas de herramientas de zonas después de corregir su desplazamiento horizontal.

Origen y SHA-256: [registro público](../../public-assets.json). La lista cerrada se valida en el límite público. No hay conexión a una vivienda. La revisión visual se hizo sobre las imágenes necesarias; no certifica un teléfono físico.

## Comparación con la maqueta

- [Ajustes, §9](../../vision-mockup.html#s9): se conservan barra superior, Guardar y secciones; se mantienen todas las opciones actuales y las siete secciones.
- [Diálogos, §11](../../vision-mockup.html#s11): tipografía, filas y acciones usan los componentes comunes. E02 convierte las tareas en páginas y reserva la ventana para confirmar sí/no. Movimientos tiene una sola vuelta arriba.
- [Editor de espacios, §14](../../vision-mockup.html#s14): conserva el dibujo como lienzo. En teléfono las herramientas se reparten en filas para no requerir desplazamiento horizontal. No se añade «Versiones guardadas» ni se cambia el historial.
- Almacenamiento y el primer espacio reutilizan encabezado, botón de vuelta y cuerpo común; su contenido funcional se conserva.
