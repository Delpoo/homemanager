# Revisión de nombre

Consulta: 28 de octubre de 2026. El propietario eligió **HomeManager** después de detectar colisiones de HomeAtlas.

Existen productos llamados [Homemanager para Homebridge](https://www.homemanager-app.de/support) y [HomeManager](https://homemanager.io/features/). El primero está directamente relacionado con domótica. Esto implica riesgo de confusión y de poca diferenciación; no constituye una conclusión legal sobre marcas.

El formulario de GitHub confirmó disponibles `Delpoo/homemanager` y `Delpoo/homemanager-instance`. El propietario autorizó el 28 de octubre de 2026 crear el primero público, el segundo privado, publicar la fundación genérica bajo MIT y mantener HomeManager como nombre de trabajo pese a las colisiones documentadas. La disponibilidad dentro de una cuenta no demuestra exclusividad comercial, de dominio o de marca.

Alternativa propuesta si decide diferenciar la marca: **Habivector**. La búsqueda web inicial no mostró una coincidencia directa; no demuestra disponibilidad de marca, dominio ni paquete. No se renombra automáticamente el proyecto.
